This Privacy Policy explains how Artha Aythaa? (ಅರ್ಥ ಆಯ್ತಾ?), a Kannada-language educational YouTube channel, handles information on this website (arthaaythaa.github.io) and in Artha Aythaa Factory, our in-house tool for publishing videos to our own YouTube channel. 1. This website

  • We do not use cookies, analytics, advertising, tracking pixels, forms or third-party scripts. Fonts and images are served from this website itself.
  • This website is hosted on GitHub Pages. GitHub may log technical information, such as visitors' IP addresses, to operate and secure its service. See the GitHub General Privacy Statement.
  • Links to YouTube, Instagram and other websites are covered by those websites' own privacy policies.

2. Artha Aythaa Factory and YouTube API Services

Artha Aythaa Factory uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). It is not a public product: only our team uses it, and it connects only to the Google account that owns the Artha Aythaa? YouTube channel. Google's handling of data is described in the Google Privacy Policy.

What it accesses, only after the account owner grants permission on Google's consent screen:

  • basic channel details (channel ID and title), to confirm that it is connected to the right channel;
  • the videos, captions, thumbnails and playlists that it uploads or updates on our channel;
  • YouTube Analytics reports for our own channel, such as views, watch time and audience retention.

How it is used: only to publish and manage videos on our own channel and to learn which videos work well, so that we can make better ones. We do not sell this information, use it for advertising, or share it with third parties.

Where it is stored: sign-in tokens and reports are stored only on our own computer, in a private folder. We do not run any servers that receive this data.

How long we keep it: analytics reports are refreshed or deleted within 30 days. If access is revoked, we delete all stored data obtained through YouTube API Services within 7 days.

Revoking access: the account owner can revoke Artha Aythaa Factory's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the stored sign-in token on our computer also disconnects the tool.

Limited Use: Artha Aythaa Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Emails and comments

If you email us, we use your email address and message only to reply to you. We do not add you to mailing lists or share your details. Comments on YouTube and Instagram are handled by those platforms under their own policies.

4. Children

Our content is made for a general audience. This website does not collect personal information from anyone, including children.
