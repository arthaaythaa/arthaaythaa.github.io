# arthaaythaa.github.io

Website of **Artha Aythaa? (ಅರ್ಥ ಆಯ್ತಾ?)**, a Kannada explainer channel: [YouTube @ArthaAythaa](https://www.youtube.com/@ArthaAythaa) · [Instagram @arthaaythaa](https://www.instagram.com/arthaaythaa/).

Plain static HTML served by GitHub Pages (no build step). Pages: home, [privacy policy](https://arthaaythaa.github.io/privacy/) and [terms of service](https://arthaaythaa.github.io/terms/), which are also the links for the channel's Google OAuth app (Artha Aythaa Factory).

Fonts in `assets/fonts` are subsets of Baloo Tamma 2, Noto Sans Kannada and Poppins, used under the SIL Open Font License (licence files alongside).
